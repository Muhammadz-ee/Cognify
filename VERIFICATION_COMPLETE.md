## 4. Smart Scripts are Ready for Download Buttons ✅

### What are Smart Scripts?
Smart Scripts allow Meta to automatically detect and track button clicks without additional code changes. This provides:
- Backup conversion tracking if fbq fails
- Enhanced button detection and analytics
- A/B testing of different button styles

### Configuration in Meta Business Manager

**Step 1: Access Smart Scripts**
1. Go to [Meta Business Manager](https://business.facebook.com)
2. Select **Pixels** → **CognifyAI Pixel** (692042883308631)
3. Click **Smart Scripts** tab

**Step 2: Create Smart Script for Main Download**
- **Script Name**: "Cognify Download Button"
- **Selector**: `.download-btn` (or see alternatives below)
- **Event**: Select **Download** from dropdown
- **Fire On**: Single click
- **Status**: Enable ✅

**Step 3: Test Smart Script**
1. Click **Test** mode button
2. Visit website in new tab
3. Click Download button
4. Return to Smart Scripts
5. You should see test event recorded

**Step 4: Activate**
1. Toggle **Enable** to turn on
2. Status should show "Active" ✅

### CSS Selectors for Smart Scripts

**Option A: Current Implementation (Recommended)**
```html
<!-- Add data attribute to button -->
<Button data-track-event="download" onClick={handleDownloadClick}>
  Download
</Button>
```
**Smart Script Selector**: `[data-track-event="download"]`

**Option B: Class-Based**

**Option C: ID-Based**

### Smart Script Benefits
| Feature | Benefit |
|---------|---------|

| **Deduplication** | Meta deduplicates with fbq using event_id |

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| "No Pixels found" in Pixel Helper | Pixel not loading in dev | Ensure `NEXT_PUBLIC_META_PIXEL_ID` is set |
| `fbq is not defined` error | Script failed to load | Check network connection, Meta CDN might be blocked |
| CAPI returns 400 error | Invalid event structure | Verify `event_id` and `event_name` are present |
| Events appear only once instead of twice | CAPI endpoint down | Check `/api/track` GET endpoint for health status |
| Events not in Meta Manager after 15 min | Deduplication working correctly | Events should be deduplicated, check unique event_ids |
| CAPI error: "Invalid access token" | Token expired or incorrect | Regenerate token in Meta Business Manager |
